AudioTools.praat~ for macOS
Universal 2 (Apple Silicon + Intel)
Built and tested: Max 9.1.4, Praat 6.4.62, macOS 26.2

INSTALL
1. Quit Max.
2. Copy the whole AudioToolsPraat folder into:
   ~/Documents/Max 9/Packages/
   (or ~/Documents/Max 8/Packages/ for Max 8)
3. Restart Max.
4. Open examples/AudioToolsPraat_mac_test.maxpat
5. Needs Praat installed at /Applications/Praat.app

The external file is:
  externals/AudioTools.praat~.mxo

Tested successfully with the AudioTools plugin scripts via bang/auto mode.
