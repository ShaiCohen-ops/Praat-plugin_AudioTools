These scripts require Python to be installed on your computer.
Follow the steps for your operating system below.
You only need to do this ONCE.

Supported scripts:
  - Paulstretch               (paulstretch.py)
  - Spectral Morph            (spectral_morph.py)
  - Waveset Distortion        (waveset_distortion.py)

  - Identity Separation       (identity_separation.py)
  - Latent Relocation         (latent_relocation.py)
  - Latent Navigation         (latent_navigation.py)
  - Latent Counterpoint       (latent_counterpoint.py)
  - Latent Spat               (latent_spat.py)


============================================================
  WINDOWS
============================================================

STEP 1 - Install Python
------------------------------------------------------------
1. Go to:  https://www.python.org/downloads/
2. Click the big yellow "Download Python" button
3. Run the installer
4. IMPORTANT: On the first screen, check the box that says
   "Add Python to PATH"  <-- do not skip this!
5. Click "Install Now"
6. When done, click "Close"

STEP 2 - Install the required packages
------------------------------------------------------------
1. Press the Windows key on your keyboard
2. Type:  cmd
3. Click "Command Prompt" to open it
4. Type the following line and press Enter:

   pip install numpy soundfile scipy scikit-learn

5. Wait for it to finish, then close the window.

TROUBLESHOOTING (Windows)
------------------------------------------------------------
"py is not recognized":
  Reinstall Python and make sure to check "Add Python to PATH"

"No module named soundfile" or "No module named sklearn":
  Open Command Prompt and run:
  pip install numpy soundfile scipy scikit-learn

"pip installed packages but Praat says they are missing":
  You may have multiple Python installations. The Praat scripts
  auto-detect which Python has the right packages. To check
  which Python pip is using, run:
    pip --version
  Then verify that same Python works:
    python -c "import numpy, soundfile, scipy, sklearn; print('OK')"
  If that fails, try:
    py -c "import numpy, soundfile, scipy, sklearn; print('OK')"


============================================================
  MAC
============================================================

STEP 1 - Install Python
------------------------------------------------------------
Mac may already have Python but it is often outdated.
Install a fresh copy:

1. Go to:  https://www.python.org/downloads/
2. Click the big yellow "Download Python" button
3. Open the downloaded .pkg file and follow the installer

STEP 2 - Install the required packages
------------------------------------------------------------
1. Open Terminal
   (Finder → Applications → Utilities → Terminal)
2. Type the following line and press Enter:

   pip3 install numpy soundfile scipy scikit-learn

3. Wait for it to finish, then close the Terminal.

NOTE: You do NOT need to edit the Praat scripts. The scripts
automatically detect whether to use "python3" or "python".

TROUBLESHOOTING (Mac)
------------------------------------------------------------
"command not found: python3":
  Try installing Python again from python.org

"No module named soundfile" or "No module named sklearn":
  Run in Terminal:
  pip3 install numpy soundfile scipy scikit-learn


============================================================
  LINUX
============================================================

STEP 1 - Install Python
------------------------------------------------------------
Python is usually already installed on Linux.
To check, open a Terminal and type:

   python3 --version

If you see a version number (e.g. Python 3.10.x) you are good.
If not, install it with your package manager:

   Ubuntu / Debian:   sudo apt install python3 python3-pip
   Fedora:            sudo dnf install python3 python3-pip
   Arch:              sudo pacman -S python python-pip

STEP 2 - Install the required packages
------------------------------------------------------------
In Terminal, type:

   pip3 install numpy soundfile scipy scikit-learn

NOTE: You do NOT need to edit the Praat scripts. The scripts
automatically detect whether to use "python3" or "python".

TROUBLESHOOTING (Linux)
------------------------------------------------------------
"pip3 not found":
  Run:  sudo apt install python3-pip   (Ubuntu/Debian)

"No module named soundfile" or "No module named sklearn":
  Run:  pip3 install numpy soundfile scipy scikit-learn
