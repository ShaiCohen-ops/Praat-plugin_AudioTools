============================================================
  HYBRID SYSTEMS
============================================================

The AudioTools plugin contains a collection of hybrid
Praat–Python systems for AI-assisted audio analysis,
recomposition, and generative sound transformation.

These systems rely on Python for numerical processing,
machine learning, and advanced audio analysis.

To run the Hybrid Systems engines you must install the
required Python packages listed below.

============================================================
  REQUIRED PYTHON PACKAGES
============================================================

Install the following packages:

    numpy
    soundfile
    scipy
    scikit-learn
    sounddevice

Quick install command:

Windows
    pip install numpy soundfile scipy scikit-learn sounddevice

Mac / Linux
    pip3 install numpy soundfile scipy scikit-learn sounddevice


============================================================
  PACKAGE PURPOSE
============================================================

numpy
    Numerical processing and matrix operations

soundfile
    Reading and writing WAV audio files

scipy
    Signal processing and spectral analysis

scikit-learn
    Machine learning algorithms used by several Hybrid Systems

sounddevice
    Multichannel audio playback for professional interfaces


============================================================
  NOTE
============================================================

Most Hybrid Systems run entirely offline and require no
internet access or external AI frameworks.

All machine learning components use lightweight libraries
and are executed locally through Python.

Praat automatically calls the Python scripts when needed.
No manual editing of the scripts is required.
