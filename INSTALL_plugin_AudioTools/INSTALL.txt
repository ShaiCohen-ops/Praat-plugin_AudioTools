============================================================
 Praat AudioTools - Installation Guide
 Using audiotools_installer.py (Windows / macOS / Linux)
============================================================

This installer downloads the latest AudioTools plugin from GitHub and
installs it into Praat's preferences folder, backing up any existing
copy first. It runs on Windows, macOS, and Linux from a single file.


------------------------------------------------------------
 REQUIREMENTS
------------------------------------------------------------
- Python 3.6 or newer (standard library only - nothing to pip install)
- An internet connection
- The file: audiotools_installer.py

To check if you have Python, open a terminal / command prompt and type:
    python --version
If that fails, try:
    py --version        (Windows)
    python3 --version   (macOS / Linux)
If none work, install Python from https://www.python.org/downloads/
On Windows, tick "Add Python to PATH" on the first install screen.


------------------------------------------------------------
 WINDOWS
------------------------------------------------------------
1. Save audiotools_installer.py somewhere you can find it,
   e.g.  C:\Users\<you>\Downloads  or  C:\Users\<you>\Praat

2. Open Command Prompt:
   Press the Start key, type  cmd , press Enter.

3. Run the installer, pointing to wherever you saved it:
       python "C:\Users\<you>\Downloads\audiotools_installer.py"

   If "python" is not recognized, try:
       py "C:\Users\<you>\Downloads\audiotools_installer.py"

   TIP - to avoid typing the long path, cd into the folder first:
       cd C:\Users\<you>\Downloads
       python audiotools_installer.py

4. Confirm the target folder when asked (it auto-detects
   C:\Users\<you>\Praat). It will download, back up, and install.

5. Restart Praat.

   Can't find the file? Search for it from cmd:
       dir /s /b C:\Users\<you>\*audiotools_installer*


------------------------------------------------------------
 macOS
------------------------------------------------------------
1. Save audiotools_installer.py, e.g. to your Downloads folder.

2. Open Terminal:
   Press Cmd+Space, type  Terminal , press Enter.

3. Run the installer:
       python3 ~/Downloads/audiotools_installer.py

   (Drag-and-drop trick: type  python3  and a space, then drag the
    .py file from Finder into the Terminal window - it pastes the
    full path for you - then press Enter.)

4. Confirm the target when asked. It auto-detects:
       ~/Library/Preferences/Praat Prefs/plugin_AudioTools

5. Restart Praat.


------------------------------------------------------------
 LINUX
------------------------------------------------------------
1. Save audiotools_installer.py, e.g. to your home or Downloads folder.

2. Open a terminal.

3. Run the installer:
       python3 ~/Downloads/audiotools_installer.py

4. Confirm the target when asked. It auto-detects:
       ~/.praat-dir/plugin_AudioTools

5. Restart Praat.


------------------------------------------------------------
 OPTIONS (all platforms)
------------------------------------------------------------
Add these after the script name if you need them:

  --yes
      Skip the confirmation prompt (install immediately).

  --dir "<path>"
      Force a specific Praat preferences folder if auto-detection
      is wrong. Example (Windows):
          python audiotools_installer.py --dir "C:\Users\<you>\Praat"

  --no-backup
      Do not back up the existing folder before overwriting.

  --branch <name>
      Install a branch other than 'main'.

Example combining options:
    python3 ~/Downloads/audiotools_installer.py --yes --no-backup


------------------------------------------------------------
 WHAT IT DOES
------------------------------------------------------------
1. Detects your Praat preferences folder for your OS.
2. Shows the target plugin folder and asks you to confirm
   (you can type a different path if the guess is wrong).
3. Downloads the latest 'main' branch from GitHub.
4. Backs up any existing plugin_AudioTools folder to a
   timestamped  plugin_AudioTools_backup_YYYYMMDD_HHMMSS  folder.
5. Installs the new files into  plugin_AudioTools .

After it finishes you will see "SUCCESS - AudioTools is installed."
ALWAYS restart Praat afterward so the menu and scripts reload.


------------------------------------------------------------
 TROUBLESHOOTING
------------------------------------------------------------
"python: can't open file ... No such file or directory"
    The path is wrong. The file is not where you typed. Search for
    it (see the Windows search command above, or use Finder/your file
    manager) and use the real full path.

"python is not recognized" (Windows)
    Python is not on PATH. Try  py  instead of  python , or reinstall
    Python and tick "Add Python to PATH".

Download fails / cannot reach GitHub
    Check your internet connection. If you are behind a corporate
    firewall or VPN, it may block  codeload.github.com . The error
    message names the step that failed.

Not sure where Praat's preferences folder is
    Inside Praat: Praat menu -> Open Praat script... -> open
    praatPrefDir.praat -> Run. It prints the exact folder. Then pass
    its parent with  --dir  if auto-detection differs.

Plugin menu does not appear after install
    Make sure you fully quit and reopened Praat (not just closed a
    window). The plugin loads only at startup.
